# OrbitalM3E

**ARTIFICIAL INTELLIGENCE WAS USED** in this project. *(Claude and Gemini models)*

Main logic is fully functional! Grab the latest version from the [Releases](https://github.com/PotatoMan2011/OrbitalM3E/releases) page.

This project was made mainly for ***Ibda'a***, its main idea is to make it easy for students and hobbyists to understand how atoms work by visualizing subshells and properties, for example. How adding a proton will change the element, an electron for an ion to form and a neutron to understand isotopes. All in a three-dimensional space to make it easy to understand.

## What makes my project unique?

1. It's free and Open Source, perfect for both students and programmers!

2. I look forward to make it as simple as it can get; modern Material 3 Expressive UI with simple buttons and toggles unlike the tools already used, which are complex and not very beginner friendly.

3. If this project succeeds, i will migrate it into other operating systems such as *Windows* and *iOS* using *KMP* (*Kotlin Multiplatform*), which allows me to share one codebase that works for these operating systems. *Android* is easier for me at the moment which is why I'm working on it.

### What would you expect from this version? 

This is a very early build of my app and is not finished. It definitely isn't my whole app. But it *is* where my core and base idea lies, updates will continue.

### What has already been done?

Crucial logic for variables regarding the subatomic particles are done. this includes: *speed, radius, tilt,* etc. 3D Canvas is fully working and optimized enough for an early version. (beta)
